# 🎮 Video Game Sales Prediction

Aplicación de **Business Intelligence** desarrollada en **MIT App Inventor** para analizar y predecir las ventas globales de videojuegos mediante **Regresión Lineal**, utilizando las ventas de Norteamérica como variable predictora.

Integra **Gemini 2.0 Flash** para complementar el análisis y la interpretación de resultados.

### 📊 Proyecto

* Dataset: **Video Game Sales — Kaggle**
* Variable predictora: `NA_Sales`
* Variable objetivo: `Global_Sales`
* Modelo: **Regresión Lineal**
* Análisis: **Correlación de Pearson**
* Muestra utilizada: **100 registros**
* Aplicación: **MIT App Inventor**
* IA generativa: **Gemini 2.0 Flash**

Durante el análisis se identificó una correlación de **R = 0.84** entre las ventas de Norteamérica y las ventas globales después del tratamiento de valores atípicos.
